# CineMatch — Movie Recommendation System

A production-ready movie recommendation system that combines **Content-Based Filtering**
and **Collaborative Filtering** using scikit-learn, Pandas, and NLTK, served through a
modern Streamlit UI.

---

## Recommendation Algorithms

| Algorithm | Implementation | Description |
|-----------|---------------|-------------|
| **Content-Based** | TF-IDF + Cosine Similarity | Finds movies similar to your pick based on plot overview, genres, keywords, cast, and director |
| **Collaborative Filtering** | NMF Matrix Factorization | Factorizes a movie × genre+keyword feature matrix into latent factors and finds similar items in latent space (item-based CF) |
| **Hybrid** | 60 % CB + 40 % CF | Best-of-both-worlds blend (default mode) |
| **Personalized** | Watch History → User Preference Vector | Averages the latent factors of watched movies to build a user preference vector, then recommends movies closest to that vector |

## Project Files

| File | Purpose |
|------|---------|
| `main.py` | Preprocesses the TMDB 5000 CSV files, builds TF-IDF + NMF models, saves artifacts |
| `app.py` | Streamlit UI — search, recommendations, watch history, taste profile |
| `requirements.txt` | Python dependencies |
| `.env.example` | Template for the TMDB API key |
| `movies.pkl` | Movie metadata (generated by main.py) |
| `similarity.pkl` | TF-IDF cosine similarity matrix (generated by main.py) |
| `cf_factors.pkl` | NMF latent factor matrix for CF (generated by main.py) |

## Setup

### 1. Add the dataset
Place both files in this directory:
- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

Download from: https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

### 2. Create and activate a virtual environment (Windows PowerShell)
```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies
```powershell
pip install -r requirements.txt
```

### 4. Download NLTK data (first time only)
```python
import nltk
nltk.download('punkt')
```

### 5. Build the recommendation models
```powershell
python main.py
```
This creates `movies.pkl`, `similarity.pkl`, and `cf_factors.pkl`.
Re-run only when the dataset or model code changes.

### 6. Configure TMDB poster API
1. Copy `.env.example` → rename to `.env`
2. Set `TMDB_API_KEY` to your TMDB v3 API Key
3. Do not share `.env` or upload it to GitHub (`.gitignore` already excludes it)

### 7. Run the app
```powershell
streamlit run app.py
```

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `movies.pkl / similarity.pkl / cf_factors.pkl not found` | Run `python main.py` first |
| `Dataset files missing` | Place both CSV files next to `main.py` |
| `TMDB API key missing` | Check `.env` is in the same folder as `app.py` |
| `401` from TMDB | Regenerate your TMDB v3 API key |
| Poster unavailable | Some TMDB records have no poster; recommendations still work |
| Collaborative mode not available | Run `main.py` to generate `cf_factors.pkl` |

## Notes

- **TF-IDF** (Term Frequency–Inverse Document Frequency) is used instead of plain
  Bag-of-Words, giving higher weight to distinctive terms and lower weight to very
  common words.
- **NMF** (Non-negative Matrix Factorization) factorizes the implicit
  movie × feature matrix into latent factors. This is the same core technique
  behind many production recommenders.  The user preference vector is computed
  as the mean of the latent factors of all watched movies.
- Porter Stemming is applied before TF-IDF vectorization to reduce vocabulary size.
- Posters are fetched in parallel (5 threads) with caching and retry logic.
